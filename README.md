## Laba1: Weather ETL

Учебный ETL-проект на Python. Программа автоматически определяет местоположение пользователя по IP, получает прогноз погоды из OpenWeatherMap на 4 дня (сегодня + 3 следующих), агрегирует данные (мин/макс температура, влажность, ветер), сохраняет их в локальную базу данных SQLite и формирует отчет в формате Markdown.

## Технологии

- Python 3.10+
- Библиотеки: requests, sqlalchemy, python-dotenv
- API: OpenWeatherMap (прогноз погоды), ipinfo.io / Nominatim (геолокация)
- База данных: SQLite (через ORM SQLAlchemy)

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd weather-etl-lab
```

2. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
source venv/bin/activate
venv\Scripts\activate
pip install -r requirements.txt
```

3. Настройте конфигурацию. Создайте файл .env на основе шаблона .env.example:

```bash
cp .env.example .env
```

Откройте файл .env и вставьте свой API-ключ от OpenWeatherMap.

4. Запустите программу:

```bash
python main.py
```

## Настройки

Основные переменные окружения в файле .env:

| Переменная | Описание | Пример значения |
|---|---|---|
| WEATHER_API_KEY | Ключ API OpenWeatherMap (обязательно) | a1b2c3d4... |
| GEO_API_FALLBACK_CITY | Резервный город, если геолокация не сработала | Sankt-Petersburg |
| DB_URL | Строка подключения к базе данных SQLite | sqlite:///weather_lab.db |
| OUTPUT_FILE | Имя файла для итогового отчета | weather_report.md |

**Важно:** Файл .env содержит секретные ключи и не должен попадать в репозиторий. В проекте используется шаблон .env.example с вымышленными данными.

## Структура проекта

Проект разделен на модули для удобства поддержки:

- main.py — главный скрипт, запускающий весь ETL-процесс последовательно
- geo_locator.py — логика определения города и координат по IP (с fallback-механизмом)
- weather_client.py — функция f() для запроса к API погоды и агрегации данных по дням
- db_models.py — описание модели базы данных (Moodel) и функции для работы с SQLAlchemy
- exporter.py — функция TOmarkdown() для выгрузки данных из БД в форматированный Markdown-файл
- .gitignore — настройки исключения файлов (БД, секреты, кэш) из Git
